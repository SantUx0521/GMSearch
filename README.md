En este proyecto realizamos una aplicacion web, donde los usuarios puedan consultar diferentes gimnasios, donde veran informacion relevante tal como su ubicacion, precio, productos en venta y maquinas disponibles.
Desarrollado con frontend en html, css y js, backend en Django (python) y base de datos manejada a traves de postgresql.
